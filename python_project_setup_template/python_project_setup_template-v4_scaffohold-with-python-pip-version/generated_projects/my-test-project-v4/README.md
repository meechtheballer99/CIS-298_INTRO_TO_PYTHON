# my-test-project-v4

This is a simple Python project that uses `requirements.txt`.

## Python Version

This project was generated for:

```text
Python >= 3.11
```

Verify your Python version:

```bash
python --version
```

Verify pip:

```bash
python -m pip --version
```

## Activate the virtual environment

```bash
source .venv/bin/activate
```

On Windows:

```powershell
.venv\Scripts\activate
```

## Install dependencies

```bash
pip install -r requirements.txt
```

If you included development tools:

```bash
pip install -r requirements-dev.txt
```

## Run

```bash
python main.py
```
