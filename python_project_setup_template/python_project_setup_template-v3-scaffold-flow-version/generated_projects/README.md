# Generated Projects

Projects created by `project-setup-helper` can be stored in this directory.

When you choose:

Step 3: Choose destination

1) Current directory
2) generated_projects/
3) Custom path

and select option 2, the helper will create projects here.

Example:

generated_projects/
├── README.md
├── weather-scraper/
├── weather-cli/
└── stock-tracker/

This directory is intentionally included in the repository as a workspace for generated projects.

Generated projects are examples of the structures taught by this repository, including:

- virtual environments
- requirements.txt projects
- pyproject.toml packages
- src layouts
- CLI applications
- Python packaging concepts
