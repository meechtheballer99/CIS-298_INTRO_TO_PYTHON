# requirements-txt-project-example

This is a simple Python project that uses `requirements.txt`.

## Activate the virtual environment

```bash
source .venv/bin/activate
```

On Windows:

```powershell
.venv\Scripts\activate
```

## Install dependencies

```bash
pip install -r requirements.txt
```

If you included development tools:

```bash
pip install -r requirements-dev.txt
```

## Run

```bash
python main.py
```
